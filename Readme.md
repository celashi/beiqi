- 真实硬件模式：
  - `python app.py`
- 模拟模式（实时模拟，不连接GPIO/电机）：
  - `python app.py --simulate`
- 自定义端口：
  - `python app.py --port 49110`
  - 可与模拟模式组合：`python app.py --simulate --port 49110`

# 系统重构后功能总览

## 1) 启动流程（开机后会发生什么）
1. 程序启动后先初始化控制器（真实模式/模拟模式）。
2. 启动后台线程：
   - 电机任务线程（串行执行动作队列）
   - 急停监听线程（监听急停事件并触发保护动作）
3. 自动执行一次“找零（homing）”：
   - **真实模式**：向下找限位，触发后再按偏移量上移，并把该点记为 0 位。
   - **模拟模式**：直接把内部位置置为 0，并标记零点已建立。
4. 零点建立成功后，Flask 服务才开始对外提供控制接口。

> 也就是说：你说的“开机自动找0，然后再进入可操作状态”已经在当前逻辑里。

## 2) 位置与目标的定义
- 内部位置变量：`current_position_mm`。
- 最大行程：`20.0 mm`。
- 前端显示的是“实际间隙”：
  - `实际间隙 = max(0, 20 - position)`。
- 自动循环时目标位置由间隙参数决定：
  - `target_pos = 20 - gap`。

## 3) 页面各按钮/功能说明

### A. 上移按钮（▲）
- 功能：向上移动。
- 行为：
  - 支持点按和长按；长按会按固定间隔连续发送 `/move`。
  - 每次 `/move` 的实际移动距离由速度动态计算（速度越高，单次步长越大）。
- 限制与保护：
  - 使用速度输入框值，速度有效范围 `0.1 ~ 10.0 mm/s`。
  - 若检测到“实际间隙 < 4.99 mm”，不会继续按原指令移动，而是触发自动找零/释放保护。

### B. 下移按钮（▼）
- 功能：向下移动。
- 行为：与上移一致（同样支持点按/长按、动态步长）。
- 限制与保护：同上移按钮。

### C. 紧急释放按钮
- 对应接口：`/home`。
- 功能：清空当前待执行动作，进入回零流程。
- 行为：
  - 若零点已建立：回到 0 位。
  - 若零点未建立：先执行找零，再回零（兜底策略）。
- 适用场景：间隙过小、状态不确定、人工希望快速回安全位。

### D. 启动循环按钮
- 对应接口：`/cycle`。
- 功能：执行自动循环动作。
- 每轮流程：
  1. 移动到目标位置（由 gap 决定）
  2. 保持 hold 秒
  3. 回到循环起始基准位
- 参数限制：
  - `gap`：`5.0 ~ 20.0 mm`
  - `speed`：`0.1 ~ 10.0 mm/s`
  - `hold`：`0.1 ~ 60.0 s`
  - `cycles`：`1 ~ 999`
- 保护行为：
  - 每轮前检测间隙，若 `< 4.99 mm` 则自动找零并重建基准，再继续后续循环。
  - 急停触发时循环会被中断。

### E. 停止功能（接口保留）
- 对应接口：`/stop`。
- 功能：立即停止电机并清空动作队列，同时清除急停标志。
- 说明：当前页面没有单独“停止”按钮，但接口可被上位机或脚本调用。

## 4) 实时状态显示
- 前端每 200ms 请求一次 `/position`。
- 返回内容包括：
  - 当前位置 `position`
  - 循环进度 `cycle_current / cycle_total`
  - 运行模式 `mode`（`real` 或 `simulate`）
- 页面展示“实际间隙”和“循环状态（就绪/移动中/循环中）”。

## 5) 安全与保护机制
- **急停按键防抖**：200ms。
- **急停触发后动作**：
  1. 立即停止电机
  2. 清空队列
  3. 提交回零任务
- **自动保护阈值**：间隙低于 `4.99 mm` 触发自动找零/释放。

## 6) 模拟模式能做什么
- 用于在无硬件（无 pigpio、无电机）环境验证控制流程。
- 保留和真实模式一致的接口与调度逻辑：`/move` `/home` `/cycle` `/stop` `/position`。
- 运动是“实时模拟”：按距离/速度计算耗时，支持中断，便于观察状态变化。

# 常用接口（便于二次开发）
- `POST /move`：`{"direction":"up|down","speed":1.0}`
- `POST /home`：紧急释放/回零
- `POST /cycle`：`{"gap":6.0,"speed":1.0,"hold":0.5,"cycles":10}`
- `POST /stop`：停止并清队列
- `GET /position`：读取位置、循环进度、运行模式
